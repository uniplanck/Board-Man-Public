# Board-Man Public Boundary

This repository is the free/open-source Board-Man edition.

It intentionally contains only code selected for public distribution. Private paid-product source code, private commercial infrastructure, signing material, customer data, payment credentials, and private anti-abuse logic are not part of this repository.

The public repository has its own Git history. It is not a fork of the private product repository and does not publish the private repository's commit history.

Security issues should be reported through the repository's security policy rather than by posting sensitive details in a public issue.
